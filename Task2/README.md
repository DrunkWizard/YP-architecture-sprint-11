# Разделение на домены:
- Домен финтех
- Домен медицинского оборудования
- Домен бухгалтерии
- Домен медицинских услуг
- Домен фармацевтики 
- Домен платформы 
- Домен ML

Почему выбрано такое разделение ?
- Домены соответствуют орг структуре компании 
- Выделение домены позволяют следовать принципу low coupling, high cohesion. Когда сущности, которые редко взаимодействуют друг с другой разделены, а сущности, которые тесно взаимодействуют находятся вместе
- Проще управлять разработкой
- В каждом домене будут свои отвественные эксперты
- Каждому домену можно выделять ресурсы в соотвествие с бизнес потребностсями 
- Развивитие ключевых продуктов независимо друг от друга
